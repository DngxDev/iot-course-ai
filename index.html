Điện áp, Dòng điện và Điện trở
🎯 Sau bài này bạn sẽ:
  • Giải thích điện áp, dòng điện, điện trở bằng analogie thực tế
  • Phân biệt DC và AC
  • Hiểu vì sao LED luôn cần điện trở
  • Tính được điện trở cần dùng cho LED bất kỳ

⚡ Analogie đường ống nước

Điện rất trừu tượng — hãy tưởng tượng hệ thống đường ống nước:

⚡
Điện áp (Voltage · V)
= Áp suất nước đẩy nước chảy. Nguồn 5V 'đẩy' electron mạnh hơn 3.3V. Arduino dùng 5V, ESP32 dùng 3.3V.
💧
Dòng điện (Current · I)
= Lưu lượng nước mỗi giây. Electron di chuyển tạo ra dòng điện. Đơn vị: Ampere (A) hay mA. 1A = 1000mA.
🚰
Điện trở (Resistance · R)
= Van chặn nước — càng chặt thì dòng chảy càng ít. Đơn vị Ohm (Ω). 1kΩ = 1000Ω.
🔋
Nguồn điện (Battery)
= Máy bơm tạo áp suất. USB 5V, pin 3.7V, adapter đều là nguồn DC một chiều.
🔑 Công thức nhớ nhanh
V = I × R  |  I = V/R  |  R = V/I
Định luật Ohm — biết 2 trong 3 thì tính được cái còn lại.

💡 LED và Điện trở

LED là linh kiện phổ biến nhất khi học nhúng. Hai đặc điểm quan trọng:

1️⃣
Cực tính — không cắm ngược
Chân dài = Anode (+). Chân ngắn = Cathode (−) → GND. Cắm ngược: LED không sáng nhưng không hỏng (nếu có điện trở).
2️⃣
Phải có điện trở!
Không có điện trở → dòng không bị giới hạn → LED cháy ngay + có thể hỏng chân GPIO của MCU.

Định luật Ohm & Tính mạch
🎯 Sau bài này bạn sẽ:
  • Áp dụng V=I×R để tính toán mạch thực tế
  • Đọc giá trị điện trở qua màu sắc (color code)
  • Phân biệt mạch nối tiếp và song song
  • Tính điện trở cho LED một cách chính xác

📐 Định luật Ohm — Công thức vàng

V = I × R
Tìm điện áp
V = I × R
Tìm dòng điện
I = V ÷ R
Tìm điện trở
R = V ÷ I
Ví dụ 1 — Tính R cho LED đỏ
Nguồn 5V | LED đỏ: Vf=2V, If=20mA=0.02A
Bước 1: Áp rơi trên R = 5-2 = 3V
Bước 2: R = 3/0.02 = 150Ω → dùng 150Ω hoặc 220Ω
Ví dụ 2 — Tính dòng qua điện trở 1kΩ
Điện trở 1000Ω, nguồn 5V:
I = V/R = 5/1000 = 0.005A = 5mA → Dòng nhỏ, an toàn cho GPIO

🔗 Nối tiếp và Song song

➡️
Nối tiếp (Series)
Linh kiện nối đuôi nhau. Cùng dòng điện. Điện áp chia đều. R = R1 + R2. Dùng với điện trở + LED.
⬆️
Song song (Parallel)
Cùng hai đầu áp. Dòng chia nhánh. Cùng điện áp. Dùng khi mắc nhiều LED cùng lúc.

Breadboard & Dụng cụ đo điện
🎯 Sau bài này bạn sẽ:
  • Hiểu cấu trúc kết nối bên trong breadboard
  • Biết dùng đồng hồ vạn năng: đo áp, thông mạch, test LED
  • Kết nối mạch LED đầu tiên không cần MCU
  • Biết cần mua gì để bắt đầu

🧱 Breadboard — Bên trong nó nối thế nào?

↔️
Dải giữa — nối ngang
5 lỗ cùng hàng ngang (A–B–C–D–E) được nối với nhau. Hàng 1 độc lập với hàng 2. Rãnh giữa ngăn đôi — IC cắm bắc qua rãnh.
↕️
Dải nguồn — nối dọc
Hai dải chạy dọc theo chiều dài: Đỏ (+) và Xanh (−/GND). Nối với nhau toàn bộ chiều dài.

🔬 Đồng hồ vạn năng (Multimeter)

①
Đo điện áp DC (V⎓)
Chọn V⎓. Que đỏ → (+), que đen → GND. Bắt đầu thang cao rồi giảm. Dùng xác nhận nguồn đang sống.
②
Đo điện trở (Ω)
Chọn Ω. Tắt nguồn mạch. 2 que lên 2 đầu điện trở. Xác nhận giá trị linh kiện.
③
Thông mạch (🔊) — quan trọng nhất!
Chọn biểu tượng loa. 2 điểm nối với nhau → CÓ TIẾNG BÍP. Dùng tìm đứt dây, breadboard hỏng, kết nối sai.
④
Test LED (Diode mode →|)
Que đỏ vào Anode (+, chân dài), que đen vào Cathode. LED SÁNG → còn tốt.
⚠️ Đo dòng điện (A/mA)
Phải cắm que đỏ vào lỗ 'A' hoặc 'mA' — không phải lỗ V/Ω. Sai → cháy cầu chì bên trong máy!

🤖 MCU là gì?

Vi điều khiển (MCU) là máy tính thu nhỏ tích hợp tất cả trên 1 chip: CPU, RAM, Flash, GPIO, ADC... Code của bạn chạy trực tiếp trên hardware — không có hệ điều hành trung gian.

🔧
CPU
Thực hiện lệnh, tính toán. 8-bit 16MHz (Arduino) đến 32-bit dual-core 240MHz (ESP32).
💾
Flash
Lưu chương trình bạn viết. Không mất khi tắt điện. 32KB (Uno) đến 4MB (ESP32).
🗂️
RAM
Lưu biến khi chạy. Mất khi tắt điện. 2KB (Uno) đến 520KB (ESP32).
📡
GPIO
Chân vào/ra kết nối với thế giới. Xuất 5V/0V, đọc nút nhấn, ADC, PWM, I2C, SPI...

💻 Cấu trúc chương trình Arduino

class="cc">// Mọi chương trình Arduino gồm 2 hàm bắt buộc

void setup() {
  class="cc">// Chạy MỘT LẦN khi khởi động
  class="cc">// Dùng để: mở Serial, cấu hình chân, khởi tạo module...
  Serial.begin(9600);         class="cc">// Mở Serial tốc độ 9600 baud
  Serial.println("Khởi động xong!");
}

void loop() {
  class="cc">// Chạy LẶP VÔ HẠN sau setup()
  class="cc">// Logic chính của chương trình nằm ở đây
  Serial.print("Thời gian: ");
  Serial.print(millis());     class="cc">// ms kể từ khi bật nguồn
  Serial.println(" ms");
  delay(1000);                class="cc">// Chờ 1 giây rồi lặp lại
}
📺 Dùng Serial Monitor
Sau khi Upload: Tools → Serial Monitor (Ctrl+Shift+M). Chọn baud rate 9600. Sẽ thấy dữ liệu từ println() theo thời gian thực.

🔴 Lỗi thường gặp

🔌 Sơ đồ kết nối

📋 Mẹo: không cần kết nối gì
Arduino Uno có LED tích hợp sẵn ở chân 13. Upload code rồi xem LED tích hợp trên board trước, sau đó mới gắn LED ngoài.

💻 Code — Giải thích từng dòng

const int LED_PIN = 13;  class="cc">// Tên cho chân 13 (dễ thay đổi sau)

void setup() {
  Serial.begin(9600);
  pinMode(LED_PIN, OUTPUT);  class="cc">// OUTPUT = MCU xuất điện áp
                              class="cc">// INPUT  = MCU đọc điện áp từ ngoài
  Serial.println("LED sẵn sàng!");
}

void loop() {
  digitalWrite(LED_PIN, HIGH);  class="cc">// HIGH = 5V → có dòng → LED sáng
  Serial.println("LED: BẬT");
  delay(1000);                  class="cc">// Chờ 1000ms = 1 giây

  digitalWrite(LED_PIN, LOW);   class="cc">// LOW = 0V → không có dòng → tắt
  Serial.println("LED: TẮT");
  delay(1000);
  class="cc">// Vòng lặp: BẬT → chờ → TẮT → chờ → BẬT → ... (mãi mãi)
}

💡 Tại sao dùng hàm?
Thay vì viết digitalWrite(4,HIGH); delay(4000); lặp lại → đặt vào hàm denDo(4000). Muốn sửa logic đèn đỏ → chỉ sửa một chỗ.
class="cc">// === ĐÈN GIAO THÔNG ===
const int DEN_DO   = 4;
const int DEN_VANG = 3;
const int DEN_XANH = 2;

void tatHet() {          class="cc">// Hàm tắt tất cả
  digitalWrite(DEN_DO,   LOW);
  digitalWrite(DEN_VANG, LOW);
  digitalWrite(DEN_XANH, LOW);
}

void denDo(int ms) {     class="cc">// Bật đèn đỏ trong ms mili giây
  tatHet();
  digitalWrite(DEN_DO, HIGH);
  delay(ms);
}

void denVang(int ms) { tatHet(); digitalWrite(DEN_VANG, HIGH); delay(ms); }
void denXanh(int ms) { tatHet(); digitalWrite(DEN_XANH, HIGH); delay(ms); }

void setup() {
  pinMode(DEN_DO, OUTPUT); pinMode(DEN_VANG, OUTPUT); pinMode(DEN_XANH, OUTPUT);
}

void loop() {
  denDo(4000);     class="cc">// 🔴 Đỏ 4 giây
  denVang(1500);   class="cc">// 🟡 Vàng 1.5 giây
  denXanh(3000);   class="cc">// 🟢 Xanh 3 giây
  denVang(1500);   class="cc">// 🟡 Vàng 1.5 giây
}

Module 3 · Kỹ thuật
Bài 3: PWM — Điều chỉnh mờ sáng LED
🎯 Sau bài này bạn sẽ:
  • Hiểu PWM tạo điện áp giả analog thế nào
  • Dùng analogWrite(pin, 0-255) điều chỉnh độ sáng
  • Xác định chân ~ hỗ trợ PWM trên Arduino
  • Tạo hiệu ứng fade in/out mượt mà

📖 PWM là gì?

MCU chỉ xuất HIGH (5V) hoặc LOW (0V). PWM bật/tắt rất nhanh với tỉ lệ khác nhau để tạo ra hiệu ứng điện áp trung gian:

🔑 Duty Cycle
Tỉ lệ thời gian bật trong một chu kỳ:
0% = tắt hoàn toàn · 50% = nửa sáng · 100% = sáng nhất
analogWrite(pin, 0-255): 0=0%, 128≈50%, 255=100%

Chỉ chân có dấu ~ mới hỗ trợ: ~3, ~5, ~6, ~9, ~10, ~11 (Arduino Uno)

🎛️ PWM Demo tương tác

analogWrite() — Kéo thanh trượt
128
Duty cycle:50% ~Điện áp:2.5V Độ sáng:Trung bình 
const int LED_PWM = 9;  class="cc">// Chân ~9 (có dấu ~ = hỗ trợ PWM)

void setup() { pinMode(LED_PWM, OUTPUT); }

void loop() {
  class="cc">// Fade IN: từ tối → sáng dần
  for (int i = 0; i <= 255; i++) {
    analogWrite(LED_PWM, i);   class="cc">// 0 = tắt, 255 = sáng nhất
    delay(8);                  class="cc">// 256 bước × 8ms ≈ 2 giây
  }
  class="cc">// Fade OUT: từ sáng → tối dần
  for (int i = 255; i >= 0; i--) {
    analogWrite(LED_PWM, i);
    delay(8);
  }
}

🤔 Vấn đề: Chân GPIO "trôi nổi"

Khi nút chưa nhấn, chân GPIO không nối với gì → điện áp không xác định, dao động ngẫu nhiên → digitalRead() trả về kết quả ngẫu nhiên!

🔴
Pull-DOWN (kéo về GND)
Điện trở 10kΩ từ chân về GND. Nút hở → LOW. Nhấn → nối 5V → đọc HIGH. Cần thêm điện trở ngoài.
🟢
Pull-UP nội (Khuyên dùng!)
INPUT_PULLUP → Arduino bật điện trở 20kΩ nội. Nút hở → HIGH. Nhấn → nối GND → đọc LOW. Không cần điện trở ngoài!
💡 Logic ngược quan trọng!
Với INPUT_PULLUP: nhấn = đọc LOW, thả = đọc HIGH. Ngược trực giác nhưng hoàn toàn bình thường. Nhớ dùng if(state == LOW) khi nhấn.
const int NUT_PIN = 2;   class="cc">// Nút nhấn ở chân D2
const int LED_PIN = 13;  class="cc">// LED ở chân D13

void setup() {
  Serial.begin(9600);
  class="cc">// INPUT_PULLUP = bật điện trở 20kΩ nội bộ
  class="cc">// Nút nhấn nối từ chân D2 về GND (không cần điện trở ngoài!)
  pinMode(NUT_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int state = digitalRead(NUT_PIN);
  class="cc">// HIGH = nút chưa nhấn (pull-up giữ 5V)
  class="cc">// LOW  = nút đang nhấn (nối xuống GND)

  if (state == LOW) {          class="cc">// Nhấn → LOW
    digitalWrite(LED_PIN, HIGH); class="cc">// Bật đèn
    Serial.println("Nhấn!");
  } else {
    digitalWrite(LED_PIN, LOW);  class="cc">// Thả → Tắt đèn
  }
  delay(10);
}

Bài 5: Toggle LED & Chống rung (Debounce)
🎯 Sau bài này bạn sẽ:
  • Hiểu hiện tượng 'nảy tiếp điểm' (contact bounce)
  • Xử lý debounce bằng phát hiện sườn xuống
  • Dùng biến bool để toggle trạng thái LED
  • Biết khi nào nên dùng millis() thay delay()
⚠️ Triệu chứng Bounce
Nhấn nút 1 lần nhưng LED bật-tắt-bật-tắt nhiều lần liên tiếp → Không phải lỗi logic! Đây là do tiếp điểm vật lý nảy 5-20ms khi đóng.
const int NUT_PIN  = 2;
const int LED_PIN  = 13;
const int DEBOUNCE = 50;    class="cc">// Chờ 50ms cho tiếp điểm ổn định

bool ledState = false;      class="cc">// Trạng thái LED hiện tại
bool nutTruoc = HIGH;       class="cc">// Trạng thái nút lần trước

void setup() {
  Serial.begin(9600);
  pinMode(NUT_PIN, INPUT_PULLUP);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  bool nutHienTai = digitalRead(NUT_PIN);

  class="cc">// Phát hiện SƯỜN XUỐNG: HIGH → LOW (ngón tay vừa chạm nút)
  if (nutHienTai == LOW && nutTruoc == HIGH) {
    delay(DEBOUNCE);  class="cc">// Chờ tiếp điểm ổn định

    if (digitalRead(NUT_PIN) == LOW) {  class="cc">// Vẫn nhấn → nhấn thật
      ledState = !ledState;             class="cc">// Toggle: đảo trạng thái
      digitalWrite(LED_PIN, ledState);
      Serial.print("LED → ");
      Serial.println(ledState ? "BẬT" : "TẮT");
    }
  }

  nutTruoc = nutHienTai;  class="cc">// Lưu lại cho lần sau
}
🔑 millis() vs delay()
delay(50) → chặn MCU 50ms, không làm gì khác được.
millis() → trả về ms từ khi bật, không chặn. Dùng khi cần xử lý nhiều việc cùng lúc:
if(millis()-lastTime >= interval) { lastTime=millis(); /* việc cần làm */ }

Bài 6: Biến trở & ADC — Tín hiệu Analog
🎯 Sau bài này bạn sẽ:
  • Hiểu ADC chuyển điện áp thành số 0-1023
  • Đọc biến trở bằng analogRead()
  • Dùng hàm map() chuyển đổi phạm vi giá trị
  • Điều chỉnh độ sáng LED theo vị trí biến trở

📖 ADC — Analog to Digital Converter

analogRead() → 0 đến 1023
Arduino Uno: ADC 10-bit → 2¹⁰ = 1024 bước
0V → 0  ·  2.5V → 511  ·  5V → 1023
Điện áp thực = analogRead() × 5.0 / 1023
📌 Chân Analog
Arduino Uno có 6 chân analog đặc biệt: A0 đến A5. Không cần pinMode() cho analog input — dùng analogRead(A0) thẳng luôn.

🎛️ ADC Demo tương tác

Mô phỏng analogRead() — Biến trở
512
analogRead():512 Điện áp:2.50V → analogWrite():128 % Đầy:50% 
class="cc">// Biến trở: A0 (chân giữa) | LED PWM: chân 9
void setup() {
  Serial.begin(9600);
  pinMode(9, OUTPUT);  class="cc">// LED ở chân ~9
}

void loop() {
  int pot = analogRead(A0);          class="cc">// Đọc biến trở: 0-1023

  class="cc">// map(value, fromLow, fromHigh, toLow, toHigh)
  int bright = map(pot, 0, 1023, 0, 255);  class="cc">// Chuyển 0-1023 → 0-255

  analogWrite(9, bright);            class="cc">// Điều chỉnh độ sáng LED

  float voltage = pot * 5.0 / 1023.0;
  Serial.print("ADC:"); Serial.print(pot);
  Serial.print("  Volt:"); Serial.print(voltage, 2);
  Serial.print("V  PWM:"); Serial.println(bright);
  delay(100);
}

Bài 7: Cảm biến ánh sáng LDR
🎯 Sau bài này bạn sẽ:
  • Hiểu LDR thay đổi điện trở theo ánh sáng
  • Lắp mạch chia áp đọc LDR bằng ADC
  • Lập trình tự động bật LED khi tối
  • Biết cách hiệu chỉnh ngưỡng
💡 LDR — Light Dependent Resistor
LDR là điện trở thay đổi theo ánh sáng:
Sáng: điện trở nhỏ (~1kΩ) → điện áp A0 thấp
Tối: điện trở lớn (~100kΩ) → điện áp A0 cao

Kết nối: 5V → LDR → A0 → 10kΩ → GND (mạch chia áp)
const int LDR_PIN = A0;
const int LED_PIN = 13;
const int NGUONG  = 500;   class="cc">// Điều chỉnh theo môi trường thực!

void setup() {
  Serial.begin(9600);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int ldr = analogRead(LDR_PIN);
  Serial.print("LDR = "); Serial.print(ldr);

  if (ldr > NGUONG) {
    digitalWrite(LED_PIN, HIGH);  class="cc">// Tối → Bật đèn
    Serial.println("  → TỐI: ĐÈN BẬT");
  } else {
    digitalWrite(LED_PIN, LOW);   class="cc">// Sáng → Tắt đèn
    Serial.println("  → SÁNG: đèn tắt");
  }
  delay(200);
}

class="cc">// Mở Serial Monitor → che LDR bằng tay → ghi giá trị tối
class="cc">// Thả tay → ghi giá trị sáng → đặt NGUONG ở khoảng giữa

class="cp">#include <DHT.h>           class="cc">// Include thư viện

class="cp">#define DHT_PIN  4
class="cp">#define DHT_TYPE DHT22

DHT dht(DHT_PIN, DHT_TYPE);  class="cc">// Tạo đối tượng DHT

void setup() {
  Serial.begin(9600);
  dht.begin();
}

void loop() {
  delay(2000);  class="cc">// DHT22 cần TỐI THIỂU 2 giây giữa các lần đọc!

  float nhietDo = dht.readTemperature();  class="cc">// Celsius
  float doAm    = dht.readHumidity();     class="cc">// %

  if (isnan(nhietDo) || isnan(doAm)) {    class="cc">// isnan = "is not a number"
    Serial.println("[LỖI] Không đọc được DHT22!");
    return;
  }

  Serial.print("Nhiệt độ: "); Serial.print(nhietDo, 1); Serial.print("°C  ");
  Serial.print("Độ ẩm: ");   Serial.print(doAm, 1);    Serial.println("%");

  if (nhietDo > 30) Serial.println("⚠️ QUÁ NÓNG!");
  if (doAm    > 80) Serial.println("⚠️ ĐỘ ẨM CAO!");
}
🔴 Lỗi thường gặp
Luôn in 'Lỗi đọc': Kiểm tra chân DATA đúng chưa, có điện trở 10kΩ pull-up chưa.
Số kỳ lạ (-40, 999): delay() quá ngắn — DHT22 cần tối thiểu 2000ms.

Bài 10: MQTT — Gửi dữ liệu lên Cloud
🎯 Sau bài này bạn sẽ:
  • Hiểu mô hình Publish/Subscribe của MQTT
  • Kết nối ESP32 với MQTT broker công cộng
  • Gửi (publish) dữ liệu cảm biến lên topic
  • Nhận (subscribe) lệnh điều khiển từ app
📡 MQTT hoạt động thế nào?
Publisher (ESP32): Gửi dữ liệu lên Broker theo 'topic'. Ví dụ: nha/nhietdo = 25.3
Broker: Trung tâm phân phối. Broker miễn phí: broker.hivemq.com
Subscriber (App): Đăng ký nhận dữ liệu theo topic, nhận ngay khi có message mới
class="cc">// Cài thư viện: PubSubClient (Nick O&class="cp">#x27;Leary)
class="cp">#include <WiFi.h>
class="cp">#include <PubSubClient.h>
class="cp">#include <DHT.h>

const char* mqtt_server = "broker.hivemq.com";  class="cc">// Broker miễn phí

WiFiClient   espClient;
PubSubClient client(espClient);
DHT dht(4, DHT22);

void callback(char* topic, byte* payload, unsigned int len) {
  String msg = "";
  for(int i=0; i<len; i++) msg += (char)payload[i];
  if (msg == "bat") digitalWrite(2, HIGH);  class="cc">// Nhận lệnh bật
  if (msg == "tat") digitalWrite(2, LOW);   class="cc">// Nhận lệnh tắt
}

void setup() {
  WiFi.begin("ssid", "pass");
  while(WiFi.status()!=WL_CONNECTED) delay(500);
  client.setServer(mqtt_server, 1883);
  client.setCallback(callback);
  dht.begin();
}

void loop() {
  if (!client.connected()) {
    client.connect("ESP32_" + String(random(9999)));
    client.subscribe("nha/lenh");     class="cc">// Nhận lệnh
  }
  client.loop();

  static long last = 0;
  if (millis()-last > 10000) {        class="cc">// Gửi mỗi 10 giây
    last = millis();
    client.publish("nha/nhietdo", String(dht.readTemperature(),1).c_str());
    client.publish("nha/doam",    String(dht.readHumidity(),1).c_str());
  }
}
